# SplitOS — Initial Request

## 1. Request type

```text
Product / technical initiative
```

## 2. Origin

Проект инициирован как идея создания отдельного дистрибутива на базе Windows 11, позволяющего использовать один персональный компьютер в двух специализированных пользовательских режимах:

```text
Work Mode
Game Mode
```

Исходная мотивация — отказаться от универсального состояния Windows, в котором рабочие и игровые процессы, службы, приложения и устройства одновременно конкурируют за ресурсы и внимание пользователя.

---

## 3. Initial request

Исходная идея:

> Взять Windows 11 как базовую платформу и создать SplitOS — отдельный дистрибутив с двумя управляемыми режимами. Work Mode должен быть очищенной и оптимизированной рабочей Windows-средой. Game Mode должен создавать глубоко оптимизированный игровой контекст, ориентированный на игры, телевизоры/игровые дисплеи, игровые клиенты и управление контроллером.

Оба режима должны использовать одну установленную Windows-базу и переключаться средствами SplitOS.

---

## 4. Initial expected value

Предполагалась следующая ценность:

- один физический ПК используется как рабочая станция и игровое устройство;
- пользователю не требуется вручную переключать большое количество Windows-настроек;
- рабочие службы и игровые службы не работают одновременно без необходимости;
- игровой режим воспринимается ближе к консольному UX;
- система сама подготавливает дисплей, ввод, звук, игровые клиенты и профиль игры;
- Windows остаётся совместимой базовой платформой для игр и desktop-приложений.

---

## 5. Initial solution hypothesis

Первая гипотеза решения:

```text
Windows 11 base
      ↓
SplitOS managed distribution
      ↓
┌──────────────┬──────────────┐
│              │              │
Work Mode      Game Mode
```

На discovery-этапе это является гипотезой продукта, а не технической архитектурой.

---

## 6. Questions immediately raised

Первичный запрос открыл вопросы:

- являются ли режимы взаимоисключающими;
- как переключать режимы;
- как разделять приложения;
- как работать с одним накопителем;
- как управлять приложениями без поддержки геймпада;
- нужен ли собственный Game Launcher;
- что делать при запуске игры из Work Mode;
- как управлять дисплеями;
- как оптимизировать настройки конкретной игры;
- как обновлять изменённый Windows-дистрибутив;
- насколько глубоко SplitOS должен контролировать Windows;
- распространяется ли SplitOS как отдельный дистрибутив или как приложение поверх существующей Windows.

Эти вопросы стали входом для дальнейшего elicitation.
